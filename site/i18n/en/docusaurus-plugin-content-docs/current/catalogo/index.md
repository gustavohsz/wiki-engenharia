Data sheets for electrical products and components, organized by category, with specifications in a standard format to make comparison and project specification easier.

## How the sheets are organized

- One folder per category (for example, conductors, circuit breakers, luminaires).
- Every sheet follows the same template: summary, specification table, application and data source.

Data comes from manufacturers' public catalogs. Always check the latest datasheet before specifying.
