Data sheets for Revit families, DWG blocks and templates used in electrical design. Each sheet includes a preview, parameters, minimum software version and a download link.

## What you will find here

- **Revit families (.rfa):** luminaires, outlets, panels, cable trays and other elements.
- **DWG blocks:** symbols and details for AutoCAD.
- **Templates:** starting files for projects.

:::warning Revit version
Revit families **cannot be opened in older versions** of the software. Check the file version on each sheet before downloading.
:::

Only original files, or third-party files whose license allows redistribution, are published. Source and license are recorded on each sheet.
