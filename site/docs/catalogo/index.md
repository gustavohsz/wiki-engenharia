Fichas de produtos e componentes elétricos, organizadas por categoria e com especificações em formato padronizado, para facilitar a comparação e a especificação em projeto.

## Como as fichas são organizadas

- Uma pasta por categoria (por exemplo, condutores, disjuntores, luminárias).
- Cada ficha segue o mesmo modelo: resumo, tabela de especificações, aplicação e fonte dos dados.

Os dados vêm de catálogos públicos dos fabricantes. Confira sempre a folha de dados mais recente antes de especificar.
